# Latch — Security self-assessment (NOT an external audit report)

**Status:** Internal draft. **No independent security auditor has been engaged.**
This document records what the LastState team has implemented and self-reviewed.
It is explicitly **not** a third-party audit, side-channel evaluation, or
certification. Treat it as an engineering status note, not assurance evidence.

See [`docs/assurance.md`](assurance.md) for the official status and the
[audit invitation](security-audit.md) for the external-review scope.

## Cryptographic Assessment

### Algorithms actually implemented
| Algorithm | Use | Status |
|-----------|-----|--------|
| XChaCha20-Poly1305 | envelope AEAD | Implemented (built-in provider is `builtin-unqualified`) |
| HKDF (SHA-256) | key derivation / domain separation | Implemented |
| SHA-256 | identity / integrity | Implemented |
| Poly1305 / ChaCha20 | primitive components | Implemented |
| HMAC (where used) | authentication | Implemented |

> The built-in crypto provider is intentionally reported as `builtin-unqualified`.
> `LS_COMMERCIAL_PROFILE=ON` fails closed unless an externally-audited provider is
> installed and passes provider KATs. See `docs/security/crypto-assurance.md`.

The following are **NOT** implemented in this repository and must not be claimed:
Ed25519 signatures, AES-256-GCM, and any "approved" third-party audit status.

### Key management
- Provisioning supports activation/rotation/revocation and fail-closed
  decommissioning; secure-element attestation is an integration boundary.
- Key derivation uses HKDF with device-specific salt.
- Hardware-backed key contracts require a CSPRNG and per-device provisioning that
  this SDK does not itself manufacture.

### Known limitations
- Self-review only; **independent cryptographic, side-channel and provisioning
  review is pending** (required before a production release per
  `docs/production-readiness.md`).
- No FIPS 140-2/3 certification.
- Secure-element support is hardware-specific and not certified by this repo.

## Threat model (summary)
| Threat | Mitigation | Status |
|--------|-----------|--------|
| Replay attacks | LEP sequence numbers + replay window | Implemented |
| Tampered telemetry | XChaCha20-Poly1305 AEAD | Implemented |
| Key extraction | Secure-element integration boundary | Integration boundary (not certified) |
| Flash wear | Bounded spool + wear leveling | Implemented |
| Supply chain (firmware signing) | Bootloader integration state | **Bootloader integration state, NOT verified signature verification** |

# Latch v0.5.0

v0.5.0 is a software-readiness hardening release intended to make the repository internally complete and fail-closed before physical product qualification.

## Release hardening

- Release packages are compiled with `LS_COMMERCIAL_PROFILE=ON`.
- Commercial artifacts are named distinctly from development artifacts.
- Release requires Required, Coverage, Quality, Mutation, Crypto Assurance, Project Readiness and Public API Compatibility gates.
- The critical mutation campaign fails on any surviving **or invalid** mutant.
- Project Readiness checks version consistency, crypto policy documentation, stale mutation claims and unresolved implementation placeholders in production source trees.
- A machine-readable public API manifest inventories installed headers and exported `ls_*` entry points; compatibility CI rejects accidental removal of a baseline public API.

## Qualification boundary

This release closes repository/software-process gaps that can be validated without the final vehicle. Hardware HIL, EMC/EMI, pressure, vibration, real power-cut, WCET/stack and final bootloader/secure-element integration remain product-qualification evidence and are deliberately not represented as completed software checks.

# Latch v0.4.0

v0.4.0 is an assurance release focused on the two remaining software-process gaps from v0.3.0.

## Commercial cryptography

The built-in portable crypto backend is no longer acceptable in the commercial profile. Commercial
builds fail closed until an externally-audited provider is installed and passes fixed KATs. Provider
metadata records name, version, assurance level and audit reference. An optional libsodium adapter is
included.

This closes the product-design dependency on unaudited in-tree crypto; it does **not** fabricate an
independent audit of Latch's own implementation or of a customer's complete AUV integration.

## Mutation assurance

The old 3-mutant smoke suite remains for speed, but a new 40-mutant critical campaign now covers
crypto, persistence, spool and transport. The qualification run killed 40/40 with zero invalid
mutants, and CI stores a machine-readable report.

## Qualification boundary

Physical HIL, key provisioning, secure-element qualification, exact third-party crypto version
approval, environmental testing and vehicle safety case remain release evidence owned by the AUV
integrator.

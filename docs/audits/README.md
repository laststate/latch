# Published audit reports

No independent external security audit has been completed yet.

When a review is completed, add a dated directory such as
`docs/audits/2026-reviewer-name/` containing the original report (or a stable
link and checksum), a maintainer response, and a completed
[`report-template.md`](report-template.md). Release notes must link to this
directory rather than claiming an audit from an issue or informal code review.

See [the audit invitation and scope](../security-audit.md) and use private
vulnerability reporting for undisclosed findings.

# Latch instructions for coding agents

Read and apply [AGENT.md](AGENT.md) in full. It is the canonical, tool-neutral
guide for AI-assisted work in this repository. Before modifying a subdirectory,
also read the nearest scoped `AGENTS.md` file.

When this file and a scoped guide differ, use the more specific rule unless it
would weaken a security, compatibility, or safety requirement in `AGENT.md`.
